# 🏔️ Carte Interactive - Stations MagicPass avec Parking Camping-Car HIVER

Carte interactive recensant les stations de ski **MagicPass 2025-2026** proposant des emplacements pour camping-car **avec accès hivernal garanti**, avec informations complètes sur les tarifs et les commodités.

## 📋 Caractéristiques

### Stations Incluses
- **17 stations de ski** partenaires MagicPass 2025-2026
- Régions: Fribourg (5), Vaud (5), Valais (7)
- **Toutes avec accès hivernal garanti pour camping-cars**
- Équipements et services hivernaux confirmés

### Informations Disponibles

Pour chaque station, vous trouverez:

#### 🏔️ Domaine Skiable
- Altitude du domaine
- Nombre de kilomètres de pistes
- Confirmation MagicPass 2025-2026

#### 🚐 Parking Camping-Car
- Capacité d'accueil
- Prix par nuit (CHF)
- Accès hivernal garanti
- Adresse exacte du parking camping-car
- Contact direct
- Descriptif court et concis
- Coordonnées GPS précises (parking, pas sommet!)

#### 🛠️ Commodités
- ⚡ Électricité
- 💧 Eau potable
- 🚿 Vidange eaux usées
- 🚻 Toilettes
- 📶 WiFi
- 🚿 Douches

## 🎯 Fonctionnalités de la Carte

### Recherche et Filtres
- **Recherche par nom** de station ou région
- **Filtre par canton** (Fribourg, Vaud, Valais)
- **Filtre par prix** (jusqu'à 20, 30 ou 40 CHF/nuit)
- **Filtre par commodités** (électricité, eau, vidange, WiFi)
- **❤️ Filtre favoris** pour marquer vos stations préférées

### Interface Interactive
- **Marqueurs colorés** selon la capacité:
  - 🟢 Vert: Plus de 15 places disponibles
  - 🟡 Jaune: Places limitées (moins de 15)
- **Popups détaillés** optimisés mobile avec toutes les informations:
  - Nom et adresse du parking camping-car
  - Coordonnées GPS précises
  - Tarifs et commodités
  - Contact et informations pratiques
  - Descriptif court
- **Liste latérale** avec aperçu rapide et tri alphabétique
- **Système de favoris** avec stockage local persistant

## 🚀 Utilisation

### Ouverture Locale
1. Téléchargez tous les fichiers du projet
2. Ouvrez `index.html` dans votre navigateur web
3. La carte se charge automatiquement avec toutes les stations

### Navigation
- Utilisez la **molette** pour zoomer/dézoomer
- **Cliquez et faites glisser** pour déplacer la carte
- **Cliquez sur un marqueur** pour voir les détails
- **Cliquez sur une station** dans la liste pour la localiser
- **Cliquez sur ❤️** pour ajouter aux favoris

## 🔄 Mise à Jour des Données

Pour ajouter une nouvelle station, modifiez `stations-data.js`:

```javascript
{
    id: 18,
    name: "Nom de la Station",
    region: "Canton - Région",
    lat: 46.xxxx,  // Coordonnées du PARKING, pas du sommet!
    lng: 7.xxxx,
    rvParking: {
        available: true,
        capacity: 20,
        winterAccess: true,
        price: 25,
        amenities: ["electricity", "water", "waste", "toilets"],
        address: "Adresse complète du parking camping-car",
        contact: "+41 XX XXX XX XX",
        notes: "Informations supplémentaires",
        shortDesc: "Description courte et concise"
    },
    skiResort: {
        altitude: "1000-2000m",
        pistes: "50km",
        magicPass: true
    }
}
```

## ℹ️ Informations Importantes

### À Savoir
- **UNIQUEMENT stations MagicPass 2025-2026** avec équipement hivernal
- Les tarifs indiqués sont donnés à titre indicatif
- Il est recommandé de **contacter la station** avant de vous déplacer
- Les places peuvent être **limitées en haute saison**
- Certains parkings nécessitent une **réservation** (Unterbäch recommandé)
- Les **coordonnées GPS** pointent vers les parkings camping-car, pas les sommets

### Stations NON Incluses
Les stations suivantes ne sont **PAS dans MagicPass 2025-2026**:
- ❌ 4 Vallées (Nendaz, Veysonnaz, Thyon, La Tzoumaz, Bruson)
- ❌ Portes du Soleil (Champéry, Morgins, Torgon, Champoussin, Les Crosets)
- ❌ Grächen, Bellwald, Vercorin, Evolène/Arolla

Les stations suivantes n'ont **PAS d'équipement hivernal**:
- ❌ Jaun (fermé en hiver)
- ❌ Les Diablerets (Lac Retaud mai-octobre seulement)

### Conseils
- Arrivez tôt pour garantir une place
- Vérifiez les conditions météo et d'accès routier
- Respectez les règles du parking
- Vidangez uniquement aux emplacements prévus
- Payez les taxes de séjour obligatoires (souvent avec avantages carte locale)
